# Recomendaciones de negocio

Propón recomendaciones concretas para mejorar la operación de un negocio de servicios recurrentes usando exclusivamente los datos proporcionados.

Prioriza acciones que ayuden a cobrar a tiempo, proteger el flujo de caja, reducir costos, mejorar márgenes y atender compromisos con proveedores. Cada recomendación debe indicar el motivo basado en los datos y el impacto esperado, sin prometer resultados.

Usa `## Diagnóstico`, `## Recomendaciones priorizadas` y `## Primeros pasos`. Limita las recomendaciones a las tres o cinco de mayor impacto y evita sugerir módulos, productos o datos que no estén justificados.
