# 07. Guías de interfaz

## Principios

- prioridad a la claridad;
- prioridad al trabajo diario;
- prioridad a pocas acciones por pantalla;
- evitar pantallas saturadas;
- evitar modales para procesos largos;
- evitar patrones complejos innecesarios.

## Dashboard operativo

Debe verse primero y debe facilitar:
- selección rápida de fecha o rango;
- visualización de atrasados;
- visualización de cobros del día;
- acceso a contacto por WhatsApp;
- validación de pagos;
- registro de promesas.

## Dashboard ejecutivo

Debe mostrar números grandes y claros:
- esperado;
- cobrado;
- pendiente;
- costos;
- utilidad.

## Formularios

Cada formulario debe:
- validar;
- mantener valores;
- mostrar errores de forma clara;
- requerir el mínimo de clics.

## Tablas

Toda tabla importante debe tener:
- búsqueda;
- paginación;
- estado visible;
- acciones rápidas.

## Estilo visual

Preferencias:
- Blade;
- Livewire;
- Tailwind CSS;
- diseño sobrio;
- colores funcionales para estados.

Colores sugeridos:
- rojo para atraso;
- amarillo para atención;
- verde para pagado;
- azul para información;
- gris para neutral.

## Interacción

El operador debe poder:
- copiar mensajes;
- abrir detalle rápido;
- validar pagos sin navegar demasiado;
- registrar gestiones en segundos.
