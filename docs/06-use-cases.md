# 06. Casos de uso

## UC-01 Crear cliente

Actor:
- usuario del sistema.

Resultado:
- un cliente queda registrado con nombre y teléfono.

## UC-02 Crear servicio del catálogo

Actor:
- usuario del sistema.

Resultado:
- se registra un producto vendible.

## UC-03 Crear servicio contratado

Actor:
- usuario del sistema.

Resultado:
- se crea la relación comercial entre cliente y servicio.

Incluye:
- precio;
- costo;
- proveedor;
- IP si aplica;
- día de cobro.

## UC-04 Ver agenda operativa

Actor:
- usuario del sistema.

Resultado:
- se muestran atrasados, hoy, mañana y promesas.

## UC-05 Registrar gestión

Actor:
- usuario del sistema.

Resultado:
- queda guardado el contacto con el cliente.

## UC-06 Registrar pago

Actor:
- usuario del sistema.

Resultado:
- se guarda el monto recibido y la evidencia.

## UC-07 Validar pago

Actor:
- usuario del sistema.

Resultado:
- el pago cambia a validado.

## UC-08 Crear promesa de pago

Actor:
- usuario del sistema.

Resultado:
- se registra la fecha futura prometida por el cliente.

## UC-09 Cancelar servicio

Actor:
- usuario del sistema.

Resultado:
- el servicio contratado deja de estar activo inmediatamente.

Debe registrarse la razón.

## UC-10 Consultar proyección financiera

Actor:
- usuario del sistema.

Resultado:
- se visualiza ingreso esperado, costo esperado y utilidad esperada en un rango definido.
