# 10. Backlog

Este archivo contiene ideas que podrían ser útiles, pero que no forman parte del MVP.

Ejemplos:
- integración con WhatsApp API;
- envío automático de recordatorios;
- varios teléfonos por cliente;
- historial de IPs;
- facturación formal;
- reportes comparativos de largo plazo;
- automatización de cobros;
- panel de auditoría;
- permisos avanzados;
- multiempresa.

Regla:
si una idea no es necesaria para operar el MVP, va aquí.
