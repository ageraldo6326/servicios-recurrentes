# 05. Módulos

## 1. Dashboard operativo

Objetivo:
- mostrar lo que debe hacerse hoy.

Incluye:
- atrasados;
- cobros del día;
- promesas para hoy;
- recordatorios de mañana;
- pagos por validar.

## 2. Dashboard ejecutivo

Objetivo:
- mostrar la salud financiera del negocio.

Incluye:
- ingresos proyectados;
- cobrado;
- pendiente;
- costos proyectados;
- utilidad proyectada;
- próximos pagos a proveedores.

## 3. Clientes

Objetivo:
- administrar clientes de forma simple.

Funcionalidad:
- crear;
- editar;
- listar;
- desactivar si aplica más adelante.

## 4. Catálogo de servicios

Objetivo:
- mantener los productos que se venden.

Ejemplos:
- Dialer 10;
- Dialer 25;
- PBX 10;
- PBX 25.

## 5. Servicios contratados

Objetivo:
- registrar la relación comercial con cada cliente.

Incluye:
- cliente;
- servicio;
- precio;
- costo;
- proveedor;
- IP;
- día de cobro;
- estatus.

## 6. Cobros

Objetivo:
- controlar el dinero esperado por período.

Incluye:
- monto;
- fecha;
- estatus;
- vínculo con servicio contratado.

## 7. Pagos

Objetivo:
- registrar el dinero recibido y su evidencia.

Incluye:
- monto;
- fecha;
- evidencia;
- validación manual.

## 8. Gestiones

Objetivo:
- guardar el historial de contacto con el cliente.

Incluye:
- tipo de gestión;
- fecha;
- resultado;
- observaciones.

## 9. Proveedores

Objetivo:
- proyectar costos y compromiso de pago mensual.

Incluye:
- catálogo de proveedores;
- condiciones de pago;
- pagos parciales;
- observaciones.
