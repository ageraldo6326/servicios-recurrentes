# 14. Sistema de Diseño

## Objetivo

Garantizar que todas las pantallas mantengan la misma identidad visual.

La carpeta:

docs/diseno/

es la fuente oficial del diseño.

Contiene:

- pantallas
- HTML
- componentes
- layouts
- estilos

Toda nueva interfaz deberá construirse tomando estas pantallas como referencia.

Nunca deberán inventarse nuevos patrones visuales si ya existe uno similar.

---

# Fuente oficial

docs/diseno/

---

# Principios

Consistencia.

Simplicidad.

Rapidez.

Pocos clics.

Jerarquía visual clara.

---

# Componentes

Antes de crear un componente nuevo, revisar si ya existe uno equivalente dentro de la carpeta de diseño.

Ejemplos:

Tablas

Botones

Filtros

Formularios

Tarjetas

Badges

Alertas

Menús

Modales

---

# Layout

Todas las pantallas nuevas deben utilizar:

El mismo layout.

La misma barra lateral.

La misma barra superior.

Los mismos márgenes.

La misma separación entre componentes.

---

# Colores

Los colores existentes tienen prioridad.

No agregar nuevas paletas.

Los estados deberán reutilizar la identidad visual existente.

---

# Tipografía

No modificar.

---

# Iconografía

Mantener el mismo paquete de iconos.

---

# Tablas

Las tablas representan el componente principal del sistema.

Deben reutilizar:

Cabeceras

Acciones

Paginación

Filtros

Estados

Badges

---

# Formularios

Todos los formularios deben seguir exactamente el mismo estilo visual.

---

# Responsive

Toda nueva pantalla debe ser responsive utilizando el mismo comportamiento definido en los diseños existentes.

---

# Regla Final

La carpeta docs/diseno representa el diseño oficial del sistema.

Si existe diferencia entre una propuesta de la IA y los archivos de diseño, siempre prevalecerá el diseño existente.
